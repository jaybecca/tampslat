# TAMPslat Output Design Templates

These are ten blank, designed output templates. They are separate from the existing authoring templates and are intended as a final presentation layer after a user has created a CV, cover letter, proposal, report, invoice, or other document.

In the Document & Business workspace, generate a document and choose **Choose a design & download**. Select one of ten visual styles, edit or paste the final text, then download the styled HTML or use Print / Save as PDF. The existing template files in `templates/` remain unchanged.

The `output-templates/` folder also contains standalone blank template pages. Open any file in a browser, enter a title, paste the generated output, apply it, then download HTML or print to PDF.

All template application happens locally in the browser. This does not configure Cloudflare secrets, storage, payments, or backend services.
