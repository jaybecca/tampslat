# File Studio restoration upgrade

File Studio opens its overview by default and loads selected units in place. ZIP adds inspect, merge and recompress. PDF adds merge, page-range split, rotate, details and typed signature marks; optimization remains Ghostscript-service-backed. Batch adds functional inventory, ZIP packaging/extraction and PDF structural re-save actions. Presentation layout is responsive and shrink-safe. File Studio header provides File Studio overview, Workspace overview and a shared theme toggle.

Password protection is not claimed because a real PDF encryption backend is not configured. Typed signature marks are not certificate-backed digital signatures. Browser runtime and service integration still require local testing.
